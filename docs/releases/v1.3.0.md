# Grimoire Exodus v1.3.0

This release makes everyday configuration easier and brings consistent native theming to the remaining Grimoire windows and dialogs.

## Highlights

- Adds a global Settings window accessible from the lower toolbar.
- Adds options to open AQW directly instead of Home and to hide lower-panel device statistics.
- Adds preferences for close confirmation and minimize-to-tray behavior, with the existing safety-oriented defaults preserved.
- Adds configurable global keyboard shortcuts for bot start and stop, upper-toolbar visibility, and supported toggle actions.
- Adds protected controls to delete saved character credentials or perform a full application reset without exposing account data.
- Adds an on-demand update check alongside the existing verified automatic update flow.
- Applies light and dark native title-bar styling consistently to Grimoire windows, Bot Manager, alerts, confirmation boxes, and supported system dialogs.
- Preserves legacy `.gbot` loading and serialization behavior, existing user-managed files, and the internal `Grimoire` assembly identity.
- Includes the private app-local Flash runtime; a separate Clean Flash installation is not required.

## Compatibility

Grimoire Exodus v1.3.0 targets AQW R0048 / Game4000r2.swf and Windows with the bundled 32-bit app-local Flash runtime. Existing user bots, settings, plugins, sets, recovery data, and account-vault data remain outside the installation payload and are preserved during normal updates.
