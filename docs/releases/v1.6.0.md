# Grimoire Exodus v1.6.0

This release introduces **Ultra Kit**, a compact live encounter companion for monitoring monsters, players, classes, levels, health, mana, positions, and duplicate-class risks without covering the AQW client. It also expands account visuals, version controls, and UI consistency while preserving the Flash.ocx default and legacy GBot behavior.

## Highlights

- **Ultra Kit:** A narrow portrait dashboard under Tools with monsters and bosses first, followed by live player details for the selected client.
- **Encounter awareness:** Includes the current account, flags duplicate classes, and enriches unresolved remote-player classes through bounded lookups against AQW's official public character page. Live packet data remains authoritative.
- **Session-safe monitoring:** Refreshes only while visible and keeps every multi-client snapshot isolated to the client that opened it.

## Additional changes

- Account Locker cards record the saved character's current name, class, and level after a successful login.
- A small portrait crop is captured from the in-game character area when the active Flash surface can be read safely. Initials remain the fallback when capture is unavailable.
- Account visuals are bounded PNG files stored under Grimoire's writable application-data directory. They contain no password, full game frame, or machine-specific path and are removed with their saved account.
- Quick Load replaces the native white list scrollbar with a thin, content-aware dark scrollbar while preserving filtering, keyboard, mouse-wheel, and selection behavior.
- Quick Load and Settings dark scroll rails now respond when the mouse wheel is used directly over the rail, including the Logs tab.
- Settings includes a Version tab for choosing verified official GitHub releases. It supports both upgrades and deliberate downgrades through the existing updater, confirmation, digest, payload, and restart safeguards.

## Compatibility

- Existing version 1 account vault files continue to load with safe empty profile fields.
- Flash.ocx remains the default game engine.
- Legacy `.gbot` serialization and execution contracts are unchanged.
- Version switching preserves writable account, settings, and GBot data. Older portable packages remain subject to the files required by their target version, while current Ruffle-capable releases must include the full Ruffle and WebView2 payload.
