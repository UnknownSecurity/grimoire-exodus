# Grimoire Exodus v1.4.0

This prerelease introduces opt-in experimental desktop multi-client support: enable it in Settings to run up to six isolated AQW clients in one Grimoire window, navigate them with compact tabs, and optionally remove the safety cap in Advanced settings.

It also improves client loading, single-instance behavior, and per-client bot isolation while preserving legacy `.gbot` compatibility and existing user data. Settings now include experimental Direct/GPU presentation requests, render quality, active-client FPS, and bot-safe inactive-client throttling.

This refreshed prerelease reduces inactive-client rendering overhead and fixes quest responses being routed to the wrong client when multiple bots are running.

Settings now includes a Logs tab for reviewing recent startup and crash diagnostics and copying a bounded, privacy-filtered support report with device information and likely errors.

Grimoire Home now includes a collapsible Contact / Report Issue form. Text-only reports can be sent through the official privacy-safe relay, while the online form handles optional GBot attachments without exposing local files to the desktop page.

The Home scrollbars and WinForms tabs now use the dark purple theme. Settings also previews the planned Flash.ocx / Ruffle engine switcher without enabling an unsupported runtime path.

Downloads include the Windows installer, portable ZIP, and SHA-256 checksums.
