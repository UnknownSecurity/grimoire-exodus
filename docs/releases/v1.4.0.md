# Grimoire Exodus v1.4.0

This prerelease introduces desktop multi-client support: run up to six isolated AQW clients in one Grimoire window, navigate them with compact tabs, and optionally remove the safety cap in Advanced settings.

It also improves client loading, single-instance behavior, and per-client bot isolation while preserving legacy `.gbot` compatibility and existing user data.

Downloads include the Windows installer, portable ZIP, and SHA-256 checksums.
