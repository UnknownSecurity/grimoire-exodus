# Grimoire Exodus v1.8.0

Pre-release desktop update focused on Modern UI engine clarity and experimental Ruffle reliability.

- Added compact Flash.ocx and Ruffle badges to the Modern UI title bar so the active engine is always clear.
- Improved Modern UI responsiveness while Ruffle is initializing, loading, and processing bridge calls.
- Fixed Ruffle combat recovery so distant targets are approached and stale defeated targets are released correctly.
- Fixed Ruffle `Kill for` progress stalling after the first requested temporary-item drop.
- Expanded engine, combat, multi-client isolation, and legacy GBot compatibility smoke coverage.
- Kept bundled Flash.ocx as the default engine and preserved the Legacy UI and existing `.gbot` behavior.

Ruffle remains experimental in this pre-release. Use the default Flash.ocx engine for the most established compatibility.
