# Grimoire Exodus v1.7.0

Stable desktop update introducing the optional Modern UI while preserving the complete Legacy interface and GBot runtime.

- Added an opt-in Modern UI with custom window controls, animated navigation, persistent AQW client mounting, Home tools, Account Locker, Cell/Pad controls, and native tool access.
- Added a Legacy/Modern selector in Settings; Modern startup now waits for the new shell without flashing the Legacy interface and falls back safely if initialization fails.
- Refined the Modern frame with a visible outline, native resize behavior, DPI-aware minimum sizing, and corrected maximize and top-edge alignment.
- Added collapsible runtime cards, multi-client-aware tabs, dark themed surfaces, and reduced-motion-safe transitions.
- Added auto-hiding scrollbars, toast feedback for bot and option changes, and an Android release card on Home.
- Fixed `Kill for` commands stalling after a cleared room leaves a stale target state.
- Added live ping to the bottom status panel, governed by the existing device-stats visibility setting.
- Kept experimental GPU presentation available with a clear warning about possible long-session visual corruption and driver instability.
- Preserved ordinary `Kill` behavior, Flash.ocx defaults, and legacy `.gbot` compatibility.
