# Grimoire Exodus v1.7.0

Pre-release desktop update focused on reliability and runtime visibility.

- Fixed `Kill for` commands stalling after a cleared room leaves a stale target state.
- Added live ping to the bottom status panel, governed by the existing device-stats visibility setting.
- Kept experimental GPU presentation available with a clear warning about possible long-session visual corruption and driver instability.
- Preserved ordinary `Kill` behavior, Flash.ocx defaults, and legacy `.gbot` compatibility.
