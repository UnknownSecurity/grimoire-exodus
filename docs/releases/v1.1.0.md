# Grimoire Exodus v1.1.0

This release establishes the modern Grimoire Exodus installation and update foundation while keeping the legacy Grimoire and GBot interfaces intact.

## Highlights

- Bundles a private app-local Flash runtime, removing the separate Clean Flash installation requirement.
- Adds a native Windows installer with optional desktop shortcut and launch-after-setup controls.
- Adds startup diagnostics, conservative orphan-state cleanup, tray controls, and crash recovery.
- Adds an encrypted Account Locker and redesigned Grimoire Home.
- Adds quick access to bundled and user-managed GBots in `Documents\Grimoire\Bot`.
- Adds verified in-app update discovery and download support for official GitHub releases.
- Restores compatibility with AQW R0048 / Game4000r2.swf and preserves legacy `.gbot` loading.
