# Grimoire Exodus v1.2.0

This release focuses on bot compatibility, responsiveness, recovery, and a smoother path from installation to everyday use.

## Highlights

- Preserves the legacy `.gbot` format and validates the available compatibility corpus without publishing local library details.
- Improves bot lifecycle cancellation, task ownership, UI-thread safety, packet handling, configuration writes, and bounded logging.
- Adds live AQW loading progress with a percentage indicator.
- Adds a cached quick-load GBot index for bundled and user-managed bots without blocking the interface.
- Adds a view-only Bot Manager and collapsible Development Roadmap to Grimoire Home.
- Makes the running primary client selectable from Home while keeping unimplemented multi-client slots locked.
- Adds verified in-app update discovery, download, merge, rollback, and restart behavior.
- Improves startup diagnostics, crash recovery, orphan cleanup, tray behavior, and native dark-mode presentation.
- Includes the app-local Flash runtime and does not require a separate Clean Flash installation.

## Downloads

- **Grimoire-Exodus-Setup-1.2.0.msi** — recommended Windows installer with optional desktop shortcut and launch-after-setup.
- **Grimoire-Exodus-Portable-1.2.0.zip** — portable package for users who prefer manual extraction.
- **SHA256SUMS.txt** — SHA-256 checksums for both release packages.

Only download Grimoire Exodus from this official GitHub repository. Third-party mirrors or repacks may contain malware, credential stealers, cryptocurrency miners, or other unwanted modifications.

## Compatibility

Grimoire Exodus v1.2.0 targets AQW R0048 / Game4000r2.swf and Windows with the bundled 32-bit app-local Flash runtime. Existing user bots, settings, plugins, sets, recovery data, and account-vault data remain outside the installation payload and are preserved during updates.
