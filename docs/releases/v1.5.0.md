# Grimoire Exodus v1.5.0

This stable release improves compatibility diagnostics, bot access, shortcut configuration, multi-client startup behavior, and game-engine choice.

## Highlights

- Adds **Grimoire Doctor** to Home for automated Windows, .NET, Flash runtime, storage, network, client-startup, and experimental-setting checks with copyable results.
- Replaces the Quick Load drop-down with a searchable, scrollable GBot selector for bundled and user-managed bots.
- Adds a compact icon-and-label Quick Load button aligned to the far right of the upper toolbar.
- Supports captured single-key and multi-key shortcut combinations with duplicate prevention and safe defaults.
- Adds an opt-in **Ruffle (experimental)** engine under Settings → Performance while keeping Flash.ocx as the recommended default and automatic compatibility fallback.
- Keeps normal launches as separate windows when multi-client mode is disabled; when enabled, later launches add a client to the existing Grimoire window.
- Refines the Settings layout with themed, content-aware scrollbars and clearer General, Performance, Key Bindings, Advanced, and Logs sections.
- Moves Bot folder and Doctor actions into their accordion headers and adds the Ko-fi support link to Home.
- Preserves legacy `.gbot` loading, existing user data, per-client bot and packet isolation, verified updater payloads, and the internal `Grimoire` assembly identity.
