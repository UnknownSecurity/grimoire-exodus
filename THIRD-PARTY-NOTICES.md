## App-local Flash Player runtime

Grimoire Exodus release packages include an app-local, patched Flash Player
ActiveX runtime obtained from the Clean Flash builds project:

- Project: <https://github.com/darktohka/clean-flash-builds>
- Runtime release: Flash Player 34.0.0.376 (`v1.54`)
- Patch tooling: <https://github.com/darktohka/FlashPatch>

Flash Player is third-party software and is not covered by Grimoire Exodus's
CC0 dedication. Adobe ended general Flash Player support in 2020. The bundled
runtime is included solely for compatibility with the legacy AQW client and
should not be used to open untrusted SWF content.
